## Как ведётся

Статус задачи — в колонке «Статус» сводки, и только там. Задача проходит
этапы по порядку проверки изменений:

| Статус | Значит |
|---|---|
| открыта | за неё ещё не брались |
| в работе | правится код (в «Ходе» указано, где: ветка, сессия) |
| сим ✓ | исправление проходит симулятор: `local/sim/run-tests.sh`, описание в `local/sim/README.md`; ждёт виртуальную машину |
| VM ✓ | прошло nvtest в виртуальной машине (`local/vm/vm.sh`); ждёт установки на хост |
| на хосте | установлено на хост (это делаете вы), ждёт проверки в игре |
| сделано | подтверждено на хосте; задача переезжает в «Сделано» с датой и коммитом |
| отложено | с причиной в «Ходе» |

Задачи не про политику (gamerec, GSP) пропускают этап симулятора.

Колонка «Тест»: сценарий симулятора, который проверяет задачу; ✗ — пока не
проходит, ✓ — проходит. Записи gamerec превращаются в такие сценарии через
`local/sim/replay.py`.

У задачи, по которой что-то происходило, есть строка «Ход» с датами: что
нашли, что сделали, коммит. Новая задача добавляется и в сводку, и в свой
раздел.
